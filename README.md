# React Game Vault

![Vite](https://img.shields.io/badge/vite-%23646CFF.svg?style=for-the-badge&logo=vite&logoColor=white)

A modern, web-based gaming console featuring a collection of classic games built with React and Vite. This project demonstrates interactive UI design, state management, and responsive web development.

## 🎮 Games Included

### 1. Hangman
A classic word-guessing game. Try to guess the hidden word letter by letter before you run out of attempts!

### 2. Memory Match
Test your memory by finding matching pairs of cards. A fun and engaging way to train your brain.

### 3. Snake
The retro arcade classic. Navigate the snake to eat food and grow longer, but be careful not to hit the walls or yourself!

### 4. Wordle
A word puzzle game where you have 6 attempts to guess a 5-letter word, with color-coded feedback to guide your next guess.

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)

### Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/UsmanBari/React-Game-Vault.git
    cd React-Game-Vault
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Start the development server**
    ```bash
    npm run dev
    ```

4.  Open your browser and navigate to `http://localhost:5173` (or the port shown in your terminal).
